# MailShelf

**Локальный менеджер email-аккаунтов для разработчиков и продвинутых пользователей**

MailShelf — десктопное приложение для хранения и управления большим количеством email-аккаунтов. Быстрый доступ к логинам, паролям, заметкам, тегам и статусам. Создано для тех, кто работает со множеством аккаунтов каждый день и хочет держать их в порядке.

**Все данные хранятся локально.** Никакого облака, синхронизации и телеметрии.

## Возможности

### Организация аккаунтов

- **Группы / Папки** — организуй аккаунты в именованные папки с цветовой маркировкой; фильтруй список по группе через сайдбар
- **Drag & drop в группы** — потяни за ручку ⠿ на карточке и брось на нужную группу в сайдбаре
- **Авто-добавление в группу** — если выбрана группа в сайдбаре, новые аккаунты автоматически попадают в неё
- **Умные теги** — автодополнение из существующих тегов, создание новых прямо в поле, фильтрация по тегу в сайдбаре
- **Инлайн-редактирование тегов** — добавляй и убирай теги прямо из карточки, не открывая форму
- **Статусы** — Active, Exhausted, Waiting Reset, Dead, Archived

### Работа с аккаунтами

- **Быстрый поиск** — полнотекстовый поиск по email, заметкам и тегам (SQLite FTS5)
- **Копирование в один клик** — email или пароль мгновенно в буфер
- **Быстрая смена статуса** — кликни на бейдж статуса прямо в карточке
- **Умные массовые действия** — выбери аккаунты по тегу / статусу / провайдеру, затем смени статус, управляй тегами, перемести в группу или удали
- **Массовое управление тегами** — добавляй или убирай теги у нескольких аккаунтов сразу
- **Диалоги подтверждения** — все деструктивные действия требуют подтверждения

### Автоматизация

- **Правила тегов** — автоматическая смена статуса по расписанию на основе тега: через N дней, в конкретный день месяца или день недели
- **Отложенное срабатывание** — если приложение было выключено и пропустило плановый запуск, правило применится сразу при следующем старте

### Прочее

- **Импорт / Экспорт** — форматы JSON и CSV для переносимых резервных копий
- **Горячие клавиши** — полная навигация с клавиатуры, нажми `?` чтобы увидеть все
- **Шифрование** — пароли шифруются AES-256-GCM, ключ защищён системным хранилищем (DPAPI / Keychain / libsecret)
- **Виртуализированный список** — тысячи аккаунтов без тормозов
- **Проверка обновлений** — при запуске проверяет GitHub Releases; скачивает и устанавливает обновления в фоне по подтверждению

## Установка

Перейди в [**Releases**](../../releases/latest) и скачай файл для своей платформы:

| Платформа | Файл |
|-----------|------|
| 🪟 Windows | `MailShelf Setup x.x.x.exe` или portable `.exe` |
| 🍎 macOS | `MailShelf-x.x.x.dmg` |
| 🐧 Linux | `MailShelf-x.x.x.AppImage` или `.deb` |

> **Предупреждение Windows SmartScreen:** при первом запуске Windows может показать «Защита Windows — неизвестный издатель». Это ожидаемо — приложение с открытым исходным кодом и пока не имеет коммерческой подписи кода.
>
> Нажми **Подробнее** → **Выполнить в любом случае**.
>
> Чтобы убедиться, что файл не был изменён, проверь SHA256-хэш на [странице релизов](../../releases/latest):
> ```powershell
> Get-FileHash .\MailShelf-Setup-x.x.x-x64.exe -Algorithm SHA256
> ```

## Группы и папки

Группы — самостоятельная сущность, хранится отдельно от тегов. У каждой группы есть название и цвет.

| Действие | Как |
|----------|-----|
| Создать группу | Нажми **+** рядом с «Groups» в сайдбаре |
| Фильтровать по группе | Кликни на название группы в сайдбаре |
| Переместить аккаунт (drag) | Потяни за ⠿ на карточке, брось на группу в сайдбаре |
| Переместить аккаунт (массово) | Выдели аккаунты → кнопка **Group** в панели массовых действий |
| Авто-назначение при создании | Сначала выбери группу — новые аккаунты попадут в неё автоматически |
| Переименовать / перекрасить | Наведи на группу → иконка карандаша |
| Удалить группу | Наведи на группу → иконка корзины → подтверждение (аккаунты становятся без группы, не удаляются) |

## Правила тегов

Правила тегов позволяют автоматизировать смену статуса по расписанию.

**Пример:** аккаунты с тегом `waiting-reset` и статусом **Waiting Reset** автоматически переходят в **Active** каждое 1-е число месяца.

**Типы триггеров:**

| Тип | Описание |
|-----|----------|
| Через N дней | Срабатывает когда статус аккаунта не менялся N дней |
| День месяца | Срабатывает в конкретный день каждого месяца (1–28) |
| День недели | Срабатывает в конкретный день каждой недели |

Правила проверяются при каждом запуске приложения и затем раз в час. Если приложение было выключено и пропустило плановые срабатывания — правило применится сразу при следующем запуске.

## Данные и приватность

| Элемент | Расположение |
|---------|--------------|
| База данных (Windows) | `%APPDATA%\mailshelf\mailshelf.db` |
| База данных (Linux) | `~/.config/mailshelf/mailshelf.db` |
| База данных (macOS) | `~/Library/Application Support/mailshelf/mailshelf.db` |
| Настройки | `settings.json` в той же папке, что и база данных |

- Пароли шифруются **AES-256-GCM** перед сохранением
- Ключ шифрования хранится в системном хранилище через Electron `safeStorage`
- Автообновление скачивает файлы с GitHub Releases по HTTPS — никакой другой сетевой активности нет
- Обновления скачиваются в фоне и устанавливаются только после нажатия **Restart & Install**

## Сборка из исходников

**Требования:** Node.js 18+

```bash
git clone https://github.com/yourname/mailshelf.git
cd mailshelf
npm install
npm run dev          # режим разработки
npm run dist:win     # сборка Windows installer + portable
npm run dist:mac     # сборка macOS DMG
npm run dist:linux   # сборка Linux AppImage + deb
```

## Выпуск новой версии

Сборка под все три платформы запускается автоматически на GitHub Actions при пуше тега версии. Используй скрипт релиза — он обновит версию, сделает коммит, тег и запушит за один шаг.

**Стабильные релизы:**

```bash
npm run release          # patch: 1.0.0 → 1.0.1
npm run release minor    # minor: 1.0.0 → 1.1.0
npm run release major    # major: 1.0.0 → 2.0.0
```

**Пре-релизы:**

```bash
npm run release:beta           # 1.0.0 → 1.0.1-beta.0
npm run release:beta minor     # 1.0.0 → 1.1.0-beta.0
npm run release:beta           # 1.0.1-beta.0 → 1.0.1-beta.1
npm run release:rc             # 1.0.0 → 1.0.1-rc.0
npm run release:stable         # 1.0.1-beta.3 → 1.0.1 (promote в stable)
```

Скрипт спросит подтверждение, затем запушит тег. GitHub Actions соберёт Windows, macOS и Linux параллельно и опубликует релиз с автоматически сгенерированным changelog.

Теги с `-` публикуются как GitHub pre-release и доставляются только пользователям, которые выбрали канал **beta** в настройках обновлений.
